# Схемы и скриншоты

В папке уже есть схема из Cisco Packet Tracer:

- `packet_tracer_topology.png`

Для защиты проекта добавлены следующие скриншоты:

| Файл | Что должно быть на скриншоте |
|---|---|
| `packet_tracer_topology.png` | вся схема сети как в задании |
| `packet_tracer_bgp.png` | вывод `show ip bgp summary` |
| `packet_tracer_hsrp.png` | вывод `show standby brief` |
| `packet_tracer_etherchannel.png` | вывод `show etherchannel summary` |
| `packet_tracer_ipsec.png` | вывод `show crypto isakmp sa` или `show crypto ipsec sa` |
| `packet_tracer_nat.png` | NAT translations после ping `8.8.8.8` |
| `packet_tracer_pings.png` | успешные ping-проверки |

Обязательный минимум - `packet_tracer_topology.png`, остальные скриншоты подтверждают работу технологий.
