# 1. Задание и цель проекта

## Исходная задача

Нужно спроектировать сеть в Cisco Packet Tracer и подготовить:

- описание сети;
- схему;
- план адресации;
- конфигурации устройств;
- проверку работоспособности.

## Выбранная топология


- слева - центральный офис;
- сверху - `Router2`, который имитирует интернет-провайдера;
- справа - филиал;
- между центральным офисом и филиалом работает GRE over IPsec.

## Что демонстрирует проект

| Технология | Где используется |
|---|---|
| VLAN | центральный офис и филиал |
| DHCP | выдача адресов пользовательским ПК |
| OSPF | внутренняя маршрутизация центрального офиса |
| BGP | маршрутизация между роутерами |
| NAT | выход центрального офиса в интернет через `Router0` и `Router1` |
| GRE | туннели между центральным офисом и филиалом |
| IPsec | защита GRE-трафика через сеть провайдера |
| HSRP | резервирование шлюза по умолчанию для ПК центрального офиса через команду `standby` |
| EtherChannel | L2-агрегация trunk-каналов между multilayer-коммутаторами |
| ACL | ограничение гостевой VLAN филиала |

## Ключевая идея

Сеть провайдера (`Router2`) используется только как транспорт. Корпоративный трафик между центральным офисом и филиалом должен идти через GRE-туннели, которые защищены IPsec. Маршруты внутренних сетей не отдаются провайдеру напрямую.
