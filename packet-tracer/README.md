Дополнительные скриншоты для защиты:

- HSRP: `show standby brief`;
- EtherChannel: `show etherchannel summary`;
- VPN: `show crypto isakmp sa`;
- NAT: `show ip nat translations`;
- туннели: `show ip interface brief`.
